Notes Changelog

What changed.

Small releases, plainly written. 0.1.3 is the current public beta. The App Store review and phone export are next.

Last updated 27 October 2026

  1. 2026-10-27

    0.1.3, the second feedback release

    New phone documents now save into Quillote's own folder and appear in Recents immediately. The old Save As used the Android create-document panel, which returns a content:// URI the file layer cannot write, so the save failed and the file never joined history. Tapping a recent file that was already open now returns to the editor instead of doing nothing. The back chevron is gone from the saved recents screen, where the file's own row is the route back; it stays for an untitled buffer, which has no row. Two fingers on the editor change the font size from 11 to 24 points, the same preference Ctrl/Cmd+= changes. Android picker names come from the provider instead of the URI. On Linux the window is held unmapped until the app has mounted, which removes the white first frame. Desktop Recents also refresh immediately after Save and close.

  2. 2026-10-26

    0.1.2, the Linux feedback release

    Undo after opening a file no longer wipes it: loading text is no longer part of the undo history. The command palette reopens after Toggle Word Wrap instead of waiting for a click in the editor. Increase Font Size and Decrease Font Size are real shortcuts, Ctrl/Cmd+= and Ctrl/Cmd+-, and both are listed in the palette. The page paints its Night background before the stylesheets load, and the native window gets the same color.

  3. 2026-10-26

    0.1.1, copy and metadata

    The empty state, About and bundle metadata now say "A tiny Markdown and code editor with Source, Live and Read." Earlier copy called Live a preview, which it is not. iOS now declares Markdown and source files so the Files app offers Quillote for .md and code. Android imports ask the content provider for the file's display name. The Linux packages state the glibc 2.39 floor: Ubuntu 24.04+, Debian 13+, Mint 22+, Fedora 40+, RHEL 10+, openSUSE Leap 16 or Tumbleweed.

  4. 2026-10-23

    0.1.0, the public beta

    Source, Live and Read for Markdown. Around 100 code languages with lazy highlighting. Night and Ink themes, with Night as the first-run default and a System option. A real command palette, crash snapshots, print, PDF export and HTML copy. iPhone and Android shells with the copy-and-share file model. The universal macOS DMG is 5.2 MB, the signed APK is 7.2 MB, and the initial JavaScript is 141.1 KB gzipped. Live mode is the focus: headings, emphasis, code and links style themselves while the Markdown stays on disk.

  5. 2026-10-22

    The Quillote rename

    The app, the bundles, the Xcode project, the Rust crate and the Android package all became Quillote. New mark, new icon sets, one identity from the window title to the App Store record.

  6. Next

    App Store review, phone export, signing

    The iPhone 0.1.0 build is in App Store review; 0.1.3 is uploaded to App Store Connect. Share-sheet export for phone files is the next mobile task. Play Store rollout for Android. Developer ID signing and notarization for the direct Mac build. A Mac App Store build needs sandboxing and security-scoped bookmarks. A read-only table preview for CSV and TSV after 1.0. None of these are done yet; this list is the plan, not a promise of dates.
