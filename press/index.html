Press Press kit

Quillote press kit.

Everything needed to write about a small Markdown editor with a real Live mode.

Updated 27 October 2026

Quillote is a tiny Markdown and code editor with a real Live mode. It opens local plain-text files and offers three views: Source, Live and Read. Live styles headings, emphasis, code and links in the buffer you are typing in, while the Markdown stays on disk. Read renders tables, KaTeX math and images. It is built by Eulogik.

The story

Quillote started with a small frustration: most Markdown editors either hide the source in a WYSIWYG view or park a preview in a second pane. Both split your attention. The file is the thing you are editing, so the file should be the thing you see.

Live mode styles the file in place. Headings, emphasis, code and links settle into place in the same buffer. The Markdown never leaves. Read is one key away for tables, KaTeX math and the finished page. The trade is deliberate: Live is an editor, not a preview pretending to be the document.

The other constraint was size. The app uses the system webview instead of bundling Chromium, ships no UI or editor fonts and has a size-tuned Rust release profile. The universal macOS DMG is 5.2 MB. The initial JavaScript is 141.7 KB gzipped. The budgets run in CI.

I wanted a Markdown editor that kept the source visible while still feeling like a document. Live styles the file in place. Read turns it into a page. Everything else, including the size, follows from that.

Gautam Kishore, founder, Eulogik
