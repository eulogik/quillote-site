Mac Markdown editor

A Markdown editor for Mac that stays out of the way.

Quillote is a 5.2 MB universal Mac app for Markdown and code. It opens local files, styles the file in Live mode, and renders a finished page in Read. No account, no telemetry, no Electron.

Updated 23 October 2026

A small editor for a big screen

Quillote is a Markdown and code editor for Mac with three views over one file. Source shows the Markdown. Live styles headings, emphasis, code and links in the buffer you are typing in. Read turns the file into a finished page with tables and KaTeX math. The file on disk never changes format.

The universal DMG is 5.2 MB. It opens local files, keeps recents on launch, and offers file associations for Markdown, text and source files. There is no account, no analytics and no update check in the beta.

What you get on macOS

  • Universal build: Apple Silicon and Intel, macOS 10.13 or later. The beta is unsigned; right-click and Open the first time.
  • Three views: Cmd+1 for Source, Cmd+2 for Live, Cmd+3 for Read.
  • A real editor: CodeMirror 6, around 100 languages, line numbers, word wrap and language detection.
  • Local files: atomic writes, encoding and line-ending detection, a 50 MB read-only cap and a binary-file refusal.
  • Print and PDF: print the page, export a PDF on macOS, or copy the rendered article as HTML.
  • Crash snapshots: a snapshot every five seconds while the buffer is dirty. Autosave is off by default on desktop.
  • Two themes: Night is ink and gold, and it is the first-run default. Ink is warm parchment. System, Light and Dark are explicit choices.

Why Live mode feels different

Most editors either hide the Markdown or park a preview in a second pane. Quillote keeps the source in the same buffer and styles it in place. You can keep typing, move the cursor, and switch back to Source with one key. Nothing is converted and nothing is hidden from the file.

Live is an editor, not a full WYSIWYG page. Tables and math wait for Read. That is a deliberate trade: the source stays readable and the file stays yours.

Where it fits

It is a good fit if you want a fast Mac Markdown editor that also opens code, keeps files on disk and has a phone app on the same core. It is not a fit if you need full WYSIWYG editing, Mermaid diagrams, DOCX export or a Mac App Store build today. For that comparison, read Quillote and Typora, honestly.

Install the beta

Download the universal DMG from the download section or the GitHub release. Open it, drag Quillote to Applications, then right-click the app and choose Open once. The beta is unsigned, so macOS will warn you the first time.

Questions

Is Quillote a native Mac app?

It is a Tauri app with a Rust backend and the system WKWebView, not Electron. That is why the universal DMG is 5.2 MB.

Does it run on Intel Macs?

Yes. The current DMG is universal: Apple Silicon and Intel, macOS 10.13 or later.

Is the Mac app on the App Store?

Not yet. The direct DMG is the beta. A Mac App Store build needs App Sandbox entitlements and security-scoped bookmarks for recents.

Does Live mode render tables and math?

No. Live styles headings, emphasis, code and links. Read renders tables and KaTeX math, and the Markdown stays in the file.

Is the DMG signed?

No. The public beta DMG is unsigned. Right-click Quillote in Applications and choose Open the first time. Developer ID signing and notarization are the next release step.
