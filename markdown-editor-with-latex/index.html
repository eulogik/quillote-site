Math Markdown and LaTeX

Markdown with LaTeX math, in the same file.

Write inline and block math in Markdown. Read renders it with KaTeX; the math chunk loads only when the document needs it. Live keeps the formula as source, so nothing is hidden.

Updated 23 October 2026

Math in the file, not in a separate tool

Quillote reads Markdown with inline and block math. Write $E = mc^2$ in a paragraph, or a block between $$ markers. Read renders it with KaTeX. There is no export step to a separate equation editor.

Inline: $E = mc^2$

Block:
$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$

Read renders it. Live keeps the source.

Live mode styles headings, emphasis, code and links, but it does not render math. The formula stays as source in the buffer. Switch to Read and the page renders with KaTeX, tables and images. That is the same file, one key away.

If you want math rendered while you type, a full WYSIWYG editor is a better fit. Quillote chooses the source-first trade: the formula is always readable as text, and the rendered page is one view away.

Why KaTeX is lazy

Math is a separate chunk. It loads only when a document contains it, and the fonts are woff2 only. A note without math never pays for the renderer. The app works offline; the formula does not make a network request.

Math and code together

A Markdown file can hold a proof, a code fence and a table. Quillote opens it in Source, styles the headings and code in Live, and renders the math and tables in Read. Code files get Source with syntax highlighting; Markdown gets all three views.

Questions

Does Quillote render LaTeX?

Yes, in Read mode. Inline and block math render through KaTeX. Live keeps the math as source; Read shows the page.

Is it MathJax or KaTeX?

KaTeX. It is a lazy chunk and ships woff2 fonts only, so the math code does not load until a document needs it.

Does it work offline?

Yes. The math renderer and fonts are local. No network request is made for a formula.

Can I write code and math in the same file?

Yes. Markdown can hold fenced code blocks and KaTeX math. Read renders both; the source stays in the same file.

Does PDF export keep the math?

The macOS PDF capture prints the rendered page, so the math is part of the output. Older macOS versions use the print dialog's Save as PDF.
