Mobile Markdown editor

Your Markdown, on your phone, without a subscription.

Quillote brings the same Source, Live and Read views to iPhone and Android. The Android APK is signed and available now. The iPhone build is App Store-signed; TestFlight and App Store review are next.

Updated 23 October 2026

The same three views, in your pocket

Quillote for iPhone and Android is not a viewer with a keyboard bolted on. It has the same Source, Live and Read views as the Mac, a formatting bar above the software keyboard, and the same dark default. Markdown files stay Markdown.

Android users can install the signed APK now. The iPhone build is App Store-signed; TestFlight and App Store review are the next step.

Live mode, on a small screen

Live styles headings, emphasis, code and links while you type. The source stays in the file, and one tap takes you back to Source. Read renders tables and KaTeX math when you want the page. The three views share one buffer, so there is nothing to sync between panes.

The phone file model

Phones do not hand apps a stable path they can write back to. Quillote copies a file you pick into its own sandbox, edits that copy, and exports through the share sheet. The original stays where it was. This avoids the silent zero-byte writes that provider URLs can cause.

  • The picker only accepts compatible text and code files. Binary files are refused.
  • Autosave is on by default on mobile. Crash snapshots run every five seconds while the buffer is dirty.
  • Uninstalling the app removes its sandbox, including copies you did not export.
  • There is no account, no sync service and no background network call.

Android today, iPhone next

The Android build is a 7.2 MB arm64 APK signed with our release key. Sideload it, open a Markdown file, and export the edit through the share sheet. The iPhone build is a 3.4 MB App Store-signed archive. TestFlight and App Store review are next; there is no public IPA.

What it does not do

There is no write-back to iCloud Drive or Google Drive, no account sync, and no CSV table view in 1.0. If you need those today, use a synced folder and open the file from the system picker. The original file is never modified until you export.

Questions

Is there a native iPhone app?

Yes. Quillote is built with Tauri and has a native iOS shell. The current build is App Store-signed; TestFlight and App Store review are the next step.

Is there an Android app?

Yes. The signed arm64 APK is available now. The Play Store rollout is next.

Does it sync between phone and Mac?

Not in the beta. There is no account or sync service. A file you open on the phone copies into the app sandbox; export the edited copy through the share sheet.

Can it write back to iCloud or Google Drive?

No. Mobile providers do not give apps a stable path they can write back to reliably, so Quillote copies the file in and exports it out. The original stays untouched until you export.

Does Live work on the phone?

Yes, with the same limits as the desktop: headings, emphasis, code and links style in place. Tables and math wait for Read.
