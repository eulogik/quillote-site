Help Support

How to get help.

Quillote is in public beta. Start here for requirements and the file model. If something is still stuck, write to us.

Updated 27 October 2026

Requirements

  • macOS: Universal build for Apple Silicon and Intel, macOS 10.13 or later. The current beta DMG is not signed or notarized.
  • iPhone: iOS 15 or later. The 0.1.0 build is in App Store review; the 0.1.3 update is uploaded to App Store Connect.
  • Android: Android 7.0 (API 24) or later. The signed APK is in the download section of this site; Play Store rollout is next.
  • Windows and Linux: CI-built installers are attached to the GitHub release. They are unsigned for now.

Opening the macOS beta

The beta is unsigned. Drag Quillote into Applications, then right-click the app and choose Open once. After that, macOS remembers it. If the app still refuses to launch, check System Settings → Privacy & Security for an Open Anyway button.

Installing on Windows

Run Quillote_0.1.3_x64-setup.exe (NSIS) or Quillote_0.1.3_x64_en-US.msi. The beta is unsigned, so SmartScreen will warn. Choose More info, then Run anyway. The MSI is the better choice for a managed or silent install; both install the same app.

Installing on Linux

The .deb and .rpm use the WebKitGTK that your distribution already ships, which is why they are under 3 MB. They are built on Ubuntu 24.04 and need glibc 2.39. Use Ubuntu 24.04 or newer, Debian 13 or newer, Linux Mint 22 or newer, Fedora 40 or newer, RHEL 10 or newer, or openSUSE Leap 16 or Tumbleweed. Ubuntu 22.04, Debian 12, RHEL 9 and Fedora 39 are too old for this build. The packages are unsigned, so the package manager will warn about the missing repository signature.

# Ubuntu 24.04+, Debian 13+, Linux Mint 22+
sudo apt install ./Quillote_0.1.3_amd64.deb

# Fedora 40+, RHEL 10+, CentOS Stream 10
sudo dnf install ./Quillote-0.1.3-1.x86_64.rpm

# openSUSE Leap 16 or Tumbleweed
sudo zypper install ./Quillote-0.1.3-1.x86_64.rpm

The AppImage is not shipped. Bundling WebKitGTK made it 82 MB, over the 10 MB installer budget. Flatpak and Snap are not in 0.1.3 either; they add a runtime and packaging maintenance that the first beta does not need. Arch users can try converting the .rpm with debtap, but that path is untested; a real AUR package waits for a real Arch test.

Changing the view

The command palette is the settings surface. Open it with Ctrl+K (Cmd+K on macOS). Every action is searchable, and each row shows its shortcut.

  • Editor font size: Ctrl+= for bigger, Ctrl+- for smaller. On macOS use Cmd. On a phone, pinch the editor with two fingers. The size runs from 11 to 24 points and is remembered between launches. The palette also lists Increase Font Size and Decrease Font Size.
  • Theme: the ... menu at the top right, or Switch Theme in the palette. System follows the desktop, Ink is the light theme, Night is the dark one.
  • Word wrap and line numbers: Toggle Word Wrap and Toggle Line Numbers in the palette.

The phone file model

Phones do not hand apps a stable path they can write back to. Quillote copies a file you pick into its own sandbox and edits that copy. A new file is saved in the same folder and appears in Recents. This is deliberate: it avoids the silent 0-byte writes that the content provider APIs can cause. Your original stays untouched. Exporting the edited copy through the share sheet is the next mobile task and is not in this beta yet.

Known issues

  • The macOS DMG is unsigned in the public beta. Developer ID signing and notarization are the next step.
  • Windows and Linux installers are CI-built and unsigned. A native smoke test on each platform is still on the list.
  • The iPhone download is not public yet. The 0.1.0 build is in App Store review, and 0.1.3 is uploaded to App Store Connect.
  • On Android, the system picker ignores extension filters. Quillote checks the picked file name before it copies anything and refuses binary files.
  • Mobile export through the share sheet is not in this beta. Saved files reopen from Recents inside Quillote.
  • Toggling word wrap or line numbers rebuilds the active view. The text and selection survive; the undo history for that document does not.

Something else?

Email hello@quillote.com with the app version, your platform, and the smallest file that reproduces the problem. If the file is private, describe the shape of it instead; do not send anything you would not want in an inbox.

You can also open an issue on the public site repository: github.com/eulogik/quillote-site/issues.
