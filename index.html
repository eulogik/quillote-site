Live mode

Live is the mode you will stay in.

This is not a preview pane bolted onto a text box. Live styles the file in the same buffer you are typing in. Headings, emphasis, inline code, links and fenced code settle into place while the Markdown stays underneath. One keystroke takes you back to Source.

Recorded in the real app, at normal typing speed. No cuts, no mockup.

Live mode, typed live. The file is still Markdown.

What Live does

  • Styles headings, bold, italic, inline code, links and fenced code
  • Keeps the source and the cursor in one place
  • Switches back to Source with one keystroke

What waits for Read

  • Tables, KaTeX math, images and the finished page
  • KaTeX loads only when a document needs it
  • Nothing is hidden from the file

What never changes

The file on disk. Markdown goes in, Markdown comes out. No database, no conversion, no format only Quillote can read.

02 The file

Nothing between you and the bytes.

No database. No proprietary document. Every note is a file you can open in any editor, forever. Quillote is a view over your disk, not a new home for your words.

Follow the build on GitHub ↗
  1. 01

    Plain text, always

    .md, .txt, source code. Nothing leaves the file system, and nothing gets rewritten into a format only we can read.

  2. 02

    Around 100 languages

    Syntax highlighting is detected from the file name, shebang or modeline. Each language is a lazy chunk, so the first file opens fast.

  3. 03

    Three views, one buffer

    Source, Live and Read share the same text. Code files stay in Source, where they belong. Markdown gets the full set.

  4. 04

    Math, tables, links, images

    Read mode handles real tables and KaTeX math, and loads KaTeX only when a document needs it. Relative images resolve against the file.

  5. 05

    A command surface, not a toolbar

    The palette, shortcuts and the 1 / 2 / 3 mode keys keep your hands on the keyboard. The phone gets a formatting bar above the keyboard.

  6. 06

    Crash-safe by default

    A snapshot every five seconds while the buffer is dirty. Autosave is off on the desktop and on for the phone. You decide what leaves the app.

  7. 07

    Print, PDF, HTML

    Print the page, export a PDF on macOS, or copy the rendered article as HTML. The file stays the source of truth.

  8. 08

    Two themes with a point of view

    Night is ink and gold. Ink is warm parchment, not a white page with a blue button. Both are built to sit with the words, not shout over them.

03 Read mode

The page, without the machinery.

Read mode turns the file into a quiet article: real tables, math, links and images. The editor stays underneath, one keystroke away.

This is Ink, the light theme. Warm parchment instead of white, amber instead of system blue. The lowest text pair measures 4.88:1.

06 Answers

The questions people ask first.

Short answers, no sales voice. If yours is missing, the support page has more.

What is Quillote?

Quillote is a small code and Markdown editor for macOS, iPhone and Android. It has three views: Source, Live and Read. It is built for people who keep their work in files, not in someone else's database.

Is Quillote free?

The public beta is free. Pricing for the 1.0 release has not been decided. If a paid tier arrives, the local editor stays usable without an account.

Does it work offline?

Yes. Quillote opens files on your disk and needs no connection. A link you click opens in your browser.

Does it collect any data?

No. There are no accounts, no analytics and no telemetry. The app does not check for updates in this beta. The only network request is a link you choose to open.

Does it support code, or only Markdown?

Both. Markdown gets Source, Live and Read. Code files get Source, with syntax highlighting for around 100 languages, line numbers and a lazy-loaded grammar per language.

Can I use it on my phone?

Yes. The iPhone and Android apps are in beta. The Android APK is signed and downloadable below; iPhone goes through TestFlight and the App Store. On mobile, a file you open copies into the app sandbox; edits leave through the share sheet. That is deliberate, because writing back to a picked provider URL is not reliable yet.

Does it support math and tables?

Read mode renders tables and KaTeX math. Live mode styles headings, emphasis, code and links; tables and math stay as source, so nothing is hidden from the file. KaTeX loads only when a document needs it.

How is it only 5.2 MB?

It uses the system webview instead of bundling Chromium, ships no UI or editor fonts, and builds Rust with LTO, one codegen unit, stripping and panic=abort. The size budgets run in CI.

Is the macOS build signed?

Not yet. The public beta DMG is unsigned, so right-click the app and choose Open the first time. Signing and notarization are the next release step.

What about Windows and Linux?

The same codebase builds on Windows and Linux. CI-built installers are attached to the GitHub release; they are unsigned for now. Windows users will see SmartScreen until a code-signing certificate is added.
